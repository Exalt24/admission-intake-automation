# Brand file: admission-intake-automation

Decided 2026-10-22 when the Zapier lead-intake lab was merged into this repository as one system.

## Name

**admission-intake-automation** (kept). It names the core workflow, the one the job post described, and it matches how the rest of the portfolio is named (descriptive, not coined: clio-matter-bridge, enterprise-rag-knowledge-base). Backups if it ever has to change: `intake-gateway`, `two-lane-intake`.

Why it was not renamed: a rename means a rebrand sweep and new links on the portfolio, the staged LinkedIn text and the profile README, and the new name would only describe the gateway, which is the smaller part.

Previous names: zapier-lead-intake-lab, zapier-lead-intake
Kept on purpose: nocode-chain-receiver | external: the name of the Worker already deployed on Cloudflare, whose URL the live Zap posts to

## Tagline

One intake front door with two lanes: admissions are written to two systems safely, contact leads are kept apart from them.

## Mark and colours

None. This is a backend repository with no interface. The hero is the recorded terminal run (`docs/demo.gif`), and no logo, icon set or palette is needed. If a social preview image is added later it comes from this file's name and tagline.
